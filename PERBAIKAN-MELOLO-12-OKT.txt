PERBAIKAN PROVIDER MELOLO

Basis: HouseDrama_Popular_MultiProvider_VAST_Diagnostic_Fix.zip

Perubahan kode:
- Provider Melolo memakai base URL https://melolo.narto-drama.com/api yang sudah dikonfigurasi di providers.ts.
- Browse mengambil daftar channel dari /get-channels, lalu meminta konten melalui /get-channel-content dengan category berupa nama kategori.
- Pencarian menggunakan /search?keyword=...
- Detail dan episode menggunakan /get-detail/{series_id} serta /get-episodes/{series_id}.
- ID video/vid dikenali sebagai ID episode untuk /get-streams-proxy/{vid}; respons proxy_url juga dikenali sebagai sumber stream.
- Ditambah fallback /get-stream/{vid} dan /get-all-streams-proxy/{series_id}.

Catatan verifikasi:
- Kode sudah diperbarui, tetapi build dan tes live API belum dapat dijalankan di lingkungan ini karena dependensi proyek tidak terpasang dan domain API tidak dapat di-resolve dari lingkungan pemeriksaan.
- Setelah deploy, jika Melolo tetap kosong, periksa status provider Melolo di dashboard admin dan buka endpoint /api/get-languages serta /api/get-channels langsung untuk memastikan layanan API hidup dan bentuk responsnya sesuai.
